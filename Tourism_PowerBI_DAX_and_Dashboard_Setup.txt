POWER BI – TOURISM DATA ANALYTICS
====================================

Dataset:
Tourism_Data_Clean.csv

Import the CSV into Power BI Desktop and rename the table:
Tourism_Data_Clean

DAX MEASURES
------------

Total Bookings =
DISTINCTCOUNT('Tourism_Data_Clean'[booking_id])

Total Revenue =
SUM('Tourism_Data_Clean'[amount])

Average Trip Cost =
AVERAGE('Tourism_Data_Clean'[amount])

Total Tourists =
DISTINCTCOUNT('Tourism_Data_Clean'[customer_id])

Average Rating =
AVERAGE('Tourism_Data_Clean'[rating])

Completed Bookings =
CALCULATE(
    [Total Bookings],
    'Tourism_Data_Clean'[booking_status] = "Completed"
)

Cancelled Bookings =
CALCULATE(
    [Total Bookings],
    'Tourism_Data_Clean'[booking_status] = "Cancelled"
)

Pending Bookings =
CALCULATE(
    [Total Bookings],
    'Tourism_Data_Clean'[booking_status] = "Pending"
)

Completion Rate =
DIVIDE(
    [Completed Bookings],
    [Total Bookings],
    0
)
